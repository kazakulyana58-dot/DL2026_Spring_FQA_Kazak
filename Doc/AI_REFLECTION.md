# Reflection: Использование AI в процессе автоматизации тестирования

В ходе выполнения данного задания я активно использовала инструменты искусственного интеллекта для написания кода, отладки и структурирования документации. Это позволило значительно ускорить процесс разработки автотестов и решить специфические проблемы с кроссбраузерностью.

## 1. Используемые инструменты
* **Gemini & Grok**: Основные инструменты для написания программной логики на Playwright (TypeScript), подбора стабильных CSS-селекторов и исправления ошибок в асинхронном коде.
* **Claude**: Использовался для написания и редактирования текстового сопровождения, формирования структуры отчетов и оформления документации проекта.

## 2. Примеры промтов

### Для отладки и написания кода (Gemini/Grok):
* **Промт по селекторам:** *"На сайте есть кнопка 'Add to Cart', реализованная через тег `<a>` с атрибутом `onclick`. Предложи несколько вариантов локаторов, которые будут устойчивы к изменениям верстки в разных браузерах."*
* **Промт по ошибкам навигации:** *"Мой тест в Playwright проходит в Chromium, но падает в Firefox на шаге `waitForURL` с ошибкой `TimeoutError`. Как сделать ожидание более стабильным, используя `Promise.all` или изменение состояния `waitUntil`?"*

### Для работы с текстом (Claude):
* **Промт по документации:** *"На основе функционала сайта Automation Test Store помоги составить краткий тест-план для модуля 'Корзина'. Выдели приоритетные проверки: добавление товара, переход к оформлению и валидацию итоговой суммы."*

## 3. Главные выводы

1.  **Эффективность в Debugging**: AI незаменим при анализе логов ошибок. Он быстрее человека замечает мелкие несоответствия в состояниях страницы (например, когда событие `load` уже произошло, а скрипт все еще ждет URL).
2.  **Кроссбраузерные различия**: Работа с AI подтвердила, что Firefox и Chromium по-разному обрабатывают сетевые задержки. Использование советов AI по "мягким" ожиданиям (`domcontentloaded`) помогло добиться 100% прохождения тестов (9 из 9).
3.  **Читаемость кода**: С помощью подсказок по локаторам удалось уйти от громоздких XPath в пользу чистых CSS-селекторов и фильтров Playwright, что делает тесты проще в поддержке.
4.  **Синтез инструментов**: Комбинация разных моделей (Grok/Gemini для логики и Claude для текстов) дает наилучший результат, позволяя использовать сильные стороны каждой нейросети.
