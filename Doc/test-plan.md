### 1.1 Тест-план

**Объект тестирования**: демонстрационный интернет-магазин https://automationteststore.com/

**Цель тестирования**: проверка работоспособности основных пользовательских сценариев интернет-магазина.

**Функциональные области и приоритеты**

| №  | Функциональная область                   | Приоритет |
|----|------------------------------------------|-----------|
| 1  | Главная страница и навигация по сайту    | P1        |
| 2  | Каталог товаров и фильтрация/сортировка  | P1        |
| 3  | Страница товара (карточка)               | P1        |
| 4  | Добавление товара в корзину              | P1        |
| 5  | Страница корзины                         | P1        |
| 6  | Процесс оформления заказа (Checkout)     | P1        |
| 7  | Авторизация и регистрация                | P2        |
| 8  | Личный кабинет (My Account)              | P2        |
| 9  | Форма обратной связи (Contact Us)        | P2        |
| 10 | Поиск по сайту                           | P2        |
| 11 | Статический контент (About Us, Privacy)  | P3        |

**Виды тестирования, которые планируется провести**

- Позитивное тестирование
- Негативное тестирование
- Тестирование граничных значений
- Интеграционное тестирование (взаимодействие корзины, чекаута, авторизации)
- Кросс-браузерное тестирование
- Тестирование адаптивности (desktop + mobile)

Не планируется: нагрузочное тестирование, тестирование безопасности, проверка реальных платежей.
