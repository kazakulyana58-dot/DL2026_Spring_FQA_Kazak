# Test Cases — Automation Test Store

**Проект:** Демонстрационный интернет-магазин https://automationteststore.com/  
**Версия:** 1.0  
**Дата создания:** 2026-03-19

5 ключевых тест-кейсов, покрывающих основные пользовательские сценарии.

## TC-001 Просмотр главной страницы и навигация по категориям

**ID:** TC-001  
**Название:** Успешная загрузка главной страницы и переход в категорию товаров  
**Приоритет:** High  
**Предусловия:** Браузер открыт, интернет-соединение есть  
**Шаги:**
1. Открыть https://automationteststore.com/
2. Убедиться, что отображаются блоки Featured, Latest, Bestsellers, Specials
3. Нажать на категорию «Skincare» (или аналогичную из меню)
4. Дождаться загрузки страницы категории

**Ожидаемый результат:**
- Главная страница загружается без ошибок
- Отображаются промо-баннеры и блоки с товарами
- Переход в категорию успешен, отображаются товары (минимум 5 шт.)


## TC-002 Добавление товара в корзину со страницы товара

**ID:** TC-002  
**Название:** Добавление товара в корзину с карточки продукта  
**Приоритет:** High  
**Предусловия:** Открыта карточка любого товара (например, Total Moisture Facial Cream)  
**Шаги:**
1. Убедиться, что отображается цена товара и поле Qty
2. Ввести количество = 2
3. Нажать кнопку «Add to Cart»
4. Подождать обновления мини-корзины / всплывающего уведомления

**Ожидаемый результат:**
- Товар добавлен в корзину (кол-во = 2)
- Обновляется счётчик корзины в шапке
- Появляется сообщение об успешном добавлении (или мини-корзина показывает товар)

**Постусловия:** Очистить корзину при необходимости

## TC-003 Просмотр и редактирование корзины

**ID:** TC-003  
**Название:** Проверка корзины: изменение количества и удаление товара  
**Приоритет:** High  
**Предусловия:** В корзине есть минимум 1 товар (добавлен по TC-002)  
**Шаги:**
1. Перейти на страницу корзины (Shopping Cart)
2. Изменить количество товара на 3 → нажать «Refresh» / обновить
3. Нажать иконку удаления (Remove) у товара
4. Подтвердить удаление (если требуется)

**Ожидаемый результат:**
- После изменения количества → итоговая сумма пересчитывается корректно
- После удаления товара → корзина становится пустой
- Отображается сообщение «Your shopping cart is empty!»


## TC-004 Регистрация нового пользователя

**ID:** TC-004  
**Название:** Успешная регистрация нового аккаунта  
**Приоритет:** Medium  
**Предусловия:** Пользователь не авторизован  
**Шаги:**
1. Перейти на страницу Login → нажать «Continue» (новый клиент)
2. Заполнить обязательные поля: First Name, Last Name, Email, Telephone, Address, City, Postcode, Country, Region/State, Password, Password Confirm
3. Согласиться с политикой конфиденциальности
4. Нажать «Continue»

**Ожидаемый результат:**
- Успешная регистрация
- Пользователь перенаправлен в личный кабинет или на страницу успеха
- Появляется сообщение «Your Account Has Been Created!»

**Постусловия:** Выйти из аккаунта

## TC-005 Отправка сообщения через форму Contact Us (негативный + позитивный)

**ID:** TC-005  
**Название:** Отправка enquiry через форму Contact Us  
**Приоритет:** Medium  
**Предусловия:** Открыта страница https://automationteststore.com/index.php?rt=content/contact  
**Шаги:**
1. Оставить поля First Name, Email, Enquiry пустыми → нажать Submit
2. Заполнить корректно: First Name = "Test", Email = "test@example.com", Enquiry = "Hello, this is a test message"
3. Нажать Submit

**Ожидаемый результат:**
- При пустых полях: отображаются ошибки валидации (обязательные поля)
- При корректных данных: появляется сообщение об успешной отправке («Your enquiry has been successfully sent...» или аналогичное)
- Нет ошибок 500 / белого экрана
